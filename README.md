## 📥 Como instalar

1. Acesse a página de [Releases](../../releases/latest)
2. Baixe a versão mais recente do TelaLink
3. Execute o instalador
4. Abra o aplicativo e comece a compartilhar

## 💻 Requisitos

* Windows 10 ou Windows 11
* Conexão com a internet

## ✨ Sobre o TelaLink

O TelaLink foi criado para facilitar o compartilhamento de tela, filmes, séries e outros conteúdos entre amigos, sem precisar configurar VPN ou lidar com processos complicados.
