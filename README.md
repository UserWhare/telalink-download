## 📥 Como instalar no Windows

1. Acesse a página de [Releases](../../releases/latest)
2. Baixe a versão mais recente do TelaLink
3. Extraia todo o conteúdo do arquivo `.zip`
4. Abra a pasta extraída
5. Execute o `TelaLink.exe`

> Não mova apenas o `TelaLink.exe` para fora da pasta. Os outros arquivos também são necessários para o aplicativo funcionar corretamente.

---

## 🚀 Como usar

1. Entre na sua conta pelo Discord ou e-mail
2. Abra o TelaLink pelo aplicativo ou navegador
3. Escolha a tela, janela ou aba que deseja compartilhar
4. Configure o áudio do computador e microfone
5. Inicie a transmissão
6. Compartilhe o link com seus amigos

Pronto. Quem receber o link pode assistir diretamente pelo navegador.

---

## 🔊 Áudio

No aplicativo para Windows, o TelaLink pode capturar o áudio geral do computador mesmo quando apenas uma janela é selecionada.

Pelo navegador, abas do Chrome e Edge podem compartilhar apenas o próprio áudio quando a opção de compartilhar áudio estiver ativada.

A disponibilidade de áudio ao compartilhar janelas pode variar de acordo com o navegador e o Windows.

## 💻 Requisitos

### Aplicativo

- Windows 10 ou Windows 11
- Conexão com a internet

### Viewer

- Navegador moderno
- Conexão com a internet
- Nenhuma instalação necessária

---

## 🔐 Contas

O TelaLink permite entrar utilizando:

- Discord
- E-mail e senha

O cadastro por e-mail aceita apenas provedores autorizados pelo serviço.

Nesta versão ainda não existe recuperação automática de senha ou confirmação de e-mail.

---

## 💬 Chat

Cada transmissão possui um chat próprio para os participantes.

As mensagens são temporárias e existem apenas durante a sessão da transmissão.

---

## ✨ Sobre o TelaLink

O TelaLink foi criado para tornar o compartilhamento de tela entre amigos simples e rápido.

A ideia é abrir, compartilhar e enviar o link, sem precisar configurar VPN, servidores ou processos complicados.

Você pode transmitir pelo aplicativo para Windows ou diretamente pelo navegador.
